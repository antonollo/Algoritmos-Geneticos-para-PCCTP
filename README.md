# Algoritmo Genético Adaptativo para PCCTP

Este repositório agrega todo o material (documentação e algoritmos) correspondente ao que foi desenvolvido durante uma atividade relacionada à Problemas de Carregamento de Contêineres em Terminal Portuário (PCCTP). O material aqui apresentado nada mais é do que uma proposta de atividade avaliativa da disciplina de Mecânica dos Sólidos e Fluidos.
O objetivo deste repositório está em tornar público tudo que foi aprendido a respeito de Computação Evolutiva, vinculado a Problemas de Otimização e Logística. O modelo de otimização empregado seguiu a estrutura de Algoritmos Genéticos Adaptativos para obtenção de uma solução ótima.
